# TestApp

A small platformer for trying the engine on a desktop, an emulator or a phone. It uses a bit of everything: character controller with double jump, pickups with a coin counter, lighting, bloom and glow, a post-process vignette, an area-limited ripple shader on the water, a screen-space UI (HUD, restart button with a wipe transition), Lua scripts, and the touch controls on Android.

Controls: A / D or the arrow keys move, Space jumps (twice in the air), Tab shows the UI focus ring. On a touch screen use the stick (left) and the round buttons (right: jump and interact); the first finger outside the controls acts as the mouse, so the Restart button is a tap.

```sh
./build/dev/bin/SIMPPlayer samples/TestApp                 # desktop
SIMP_TOUCH=1 ./build/dev/bin/SIMPPlayer samples/TestApp    # desktop with the touch overlay (mouse acts as a finger)
Android/build.sh samples/TestApp debug                     # APK, see docs/ANDROID.md
```

It also opens in the editor (`SIMPEditor samples/TestApp`). The scene is generated by `make_scene.py` so the layout is easy to change: edit the script and run it.
